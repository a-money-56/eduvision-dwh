3. DÉROULEMENT DES OPÉRATIONS ETL (Extract, Transform, Load)

Phase 1 : Extraction (Extract)
Contexte de l'existant : Données dispersées et non structurées (fichiers Excel, relevés papier, WhatsApp).
Action : Simulation de l'existant via des fichiers sources .xlsx (Étudiants, Matières, Notes).
Défi : Hétérogénéité des formats et encodage.
Solution : Utilisation de la bibliothèque pandas pour ingérer les fichiers de manière standardisée.

Phase 2 : Transformation (Transform) - Le cœur du nettoyage
C'est l'étape la plus critique pour garantir la qualité de la donnée (Data Quality).
Nettoyage syntaxique : Uniformisation des noms de colonnes (suppression des espaces, mise en minuscules) via df.columns.str.strip().str.lower().
Nettoyage sémantique : Harmonisation des données catégorielles (ex: transformer "MASCULIN", "Homme", "M" en une seule valeur "M").
Calcul de mesures dérivées : Calcul automatique de la moyenne_finale et du statut (Valide/Échoue) à partir des notes brutes (CC et Examen).
Gestion des dimensions : Création de la dimension Temps (id_temps) pour respecter la structure du schéma en étoile et éviter la redondance dans la table de faits.

Phase 3 : Chargement (Load)
Stratégie : Chargement séquentiel. Les tables de dimensions (dim_etudiant, dim_matiere, etc.) sont chargées en premier pour garantir l'intégrité référentielle avant l'insertion de la table de faits (fait_performance).
Outil : SQLAlchemy pour mapper les DataFrames Pandas vers les tables PostgreSQL.


4. DÉFIS TECHNIQUES RENCONTRÉS ET RÉSOLUTIONS (Très important pour le jury)
Si le jury demande : "Quelles difficultés avez-vous rencontrées ?"
Problème d'intégrité référentielle (Clés étrangères) :
Erreur : psycopg2.errors.UndefinedColumn et violations de contraintes.
Cause : Le fichier Excel de "faits" contenait des attributs de dimension (ex: annee_academique) qui n'existaient pas dans la table de faits du schéma en étoile.
Résolution : Application du principe de normalisation du DWH. Suppression des colonnes redondantes dans le DataFrame Python avant l'insertion, en ne gardant que la clé étrangère id_temps.
Problème d'idempotence (Doublons) :
Erreur : UniqueViolation: la valeur d'une clé dupliquée rompt la contrainte unique.
Cause : Exécution multiple du script ETL lors de la phase de test.
Résolution : Mise en place d'une procédure de "Truncate before Load" (vidage des tables via la commande SQL TRUNCATE TABLE ... CASCADE) pour garantir un environnement propre à chaque exécution du pipeline.
Problème de "Data Wrangling" (Données sales) :
Erreur : KeyError: 'note_cc'.
Cause : Incohérence entre les noms de colonnes du fichier source (ex: "Note CC ") et le code Python.
Résolution : Automatisation du nettoyage des métadonnées (noms de colonnes) via les fonctions vectorielles de Pandas.
