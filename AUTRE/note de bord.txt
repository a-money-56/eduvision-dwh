ÉTAPE 5 : Démontrer les capacités OLAP (Pour la soutenance)
Partie A : Le "Drill-down" et le "Slice" dans Power BI
Action 1 : Créer une Matrice (Pour le Drill-down / Roll-up)
Le Drill-down permet de passer du global au détail (ex: de la Filière à la Matière).
Dans Power BI, clique dans un espace vide.
Dans le volet Visualisations, choisis l'icône Matrice (Matrix - elle ressemble à un tableau avec des petites flèches bleues).
Glisse les champs suivants :
Lignes : nom_filiere (de dim_filiere) ET nom_matiere (de dim_matiere). (Power BI va créer une hiérarchie).
Valeurs : moyenne_finale (de fait_performance).
Important : Clique sur la petite flèche à côté de moyenne_finale dans "Valeurs" et choisis Moyenne (et non Somme).
Résultat : Tu as un tableau où tu peux cliquer sur le petit "+" à côté d'une filière pour voir le détail des matières. C'est exactement le Drill-down !
Action 2 : Ajouter des Segments (Pour le Slice / Dice)
Le Slice permet de filtrer le cube de données sur un axe précis (ex: voir uniquement les filles).
Clique dans un espace vide.
Dans Visualisations, choisis l'icône Segment (Slicer - un petit entonnoir avec une liste).
Glisse le champ sexe (de dim_etudiant) dans la zone Champ.
Fais pareil pour créer un deuxième segment avec semestre (de dim_temps).
Résultat : Quand tu cliques sur "F" dans le segment Sexe, tous tes graphiques (ta matrice, tes barres) se recalculent instantanément pour ne montrer que les filles. C'est le Slice !
